# ialeixo
Sylvain Schmitt
Jun 16, 2026

Analyses developed during the post doc of Izabella Aleixo at INPA on
modelling the effect of FACE Amazonia on forest dynamics with TROLL and
analysing photosynthetic leaf efficiency with leaf age.

**ialeixo** includes:

- `izablea.qmd` codes to manipulate rcontroll with version 4
- `pheno.qmd` example code to model photosynthetic leaf efficiency with
  leaf age
- `pheno3.qmd` modelling of photosynthetic leaf efficiency with leaf age
  with real data
